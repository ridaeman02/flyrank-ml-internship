## 1. Typography

- **Heading Font:** JetBrains Mono (gives a crisp, technical ML engineering feel).
- **Body Font:** Inter (highly legible, neutral, and clean for long-form case studies).

## 2. Palette (The 4-Color Tight Palette)

- **Background:** `#FAFAFA` (Near-white, soft on the eyes)
- **Text:** `#1E1E1E` (Near-black, high contrast but not harsh)
- **Accent:** `#3B82F6` (Slate Blue, used sparingly for links and primary buttons)
- **Muted/Borders:** `#94A3B8` (Slate Gray, for subtle dividers)

## 3. Logo / Favicon

I created a clean, simple monogram ("RE" for Rida Eman). It uses a near-black circle background with near-white geometric letters carved out, keeping it entirely aligned with the tight palette.

## 4. The Claude Project Style Note

**Instructions added to my Claude Project:**
> **Style Note:** Use 'Inter' for body text and 'JetBrains Mono' for headings. The palette is minimalist: #FAFAFA (bg), #1E1E1E (text), and #3B82F6 (accent). 
> **Mood:** The mood is calm, technical, and highly structured—the design should never compete with the data or the code.
